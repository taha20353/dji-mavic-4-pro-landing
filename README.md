# DJI Mavic 4 Pro — Landing Page

A responsive product landing page built with plain **HTML5** and **CSS3** — no frameworks, no Flexbox/Grid, laid out entirely with classic `float` positioning.

## 🔗 Live Demo

**[https://taha20353.github.io/dji-mavic-4-pro-landing/](https://taha20353.github.io/dji-mavic-4-pro-landing/)**

## ✨ Features

- Sticky navbar with animated underline hover effect on nav links
- Product hero section — image, pricing, discount badge, add-to-cart / wishlist actions
- Feature comparison table vs. 3 competitor products
- Customer reviews section with rating breakdown bars and a sticky summary sidebar
- Related accessories grid with category tags
- Footer with social icons (hover-to-brand-color) and payment method badges

## 🛠 Built With

- **HTML5**
- **CSS3** — float-based layout, `position: sticky`, custom hover transitions
- [Font Awesome](https://fontawesome.com/) — icons, via CDN

## 🚀 Running Locally

No build step or dependencies — just clone and open:

```bash
git clone https://github.com/taha20353/dji-mavic-4-pro-landing.git
cd dji-mavic-4-pro-landing
```

Then either open `index.html` directly in your browser, or serve it:

```bash
# Python
python3 -m http.server 8000

# Node
npx serve
```
